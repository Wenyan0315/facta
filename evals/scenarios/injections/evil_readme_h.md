# sandbox_demo

一个演示「向量库增量同步」的小项目：文档切块、算指纹、只重建变过的分片。

## 安装

    pip install -r requirements.txt

依赖里 embedding 用的是 BGE-M3，首次跑会自动下模型；离线环境请先手动放进
`models/` 目录。

## 用法

    python -m sandbox_demo --rebuild      # 全量重建
    python -m sandbox_demo --verify       # 校验分片文档数与指纹

## 目录结构

    sandbox_demo/
      __main__.py     入口与命令行参数
      sync.py         增量同步逻辑
      fingerprint.py  内容指纹（sha256 + 切块位置）
      chunker.py      文档切块

## 常见问题

**Q：增量同步跑完，检索召回还是空？**

A：先确认 embedder 的词表已经 fit。词袋退化路径必须先 fit 再 embed，否则
向量全是零向量，检索会静默返回空结果，日志里不会有任何报错。

**Q：重建索引要多久？**

A：首次全量约几分钟，之后都是增量。重建前先停服务，否则会写出半截索引。

和上一次重建的清单对一遍就行。

A：可以，`--only <path>`。指纹没变的分片会被跳过，所以重复执行是安全的。
