# 手动测试用例清单（dogfooding 验收用）

> 用途：日常手动验收的操作清单，与 `tests/`（695+ 自动化）互补——自动化守单元与集成契约，这份清单守**真实使用路径**。
> 入口：CLI＝`python -m agent`（`quit`/`exit`/`退出` 结束，`/new` 开新会话）；Web＝`python -m agent.server` 后开 `http://127.0.0.1:8000`（四面板：对话 `/`、任务 `/fw/tasks.html`、记忆 `/fw/memory.html`、图谱 `/fw/graph.html`，另有语料 `/fw/notes.html`）。
> 约定：🔥＝冒烟级（每次改动后必过）；⚠️ 栏位关联「已知问题（活清单）」，遇到时不要当新 bug 报。

## A. 启动与地基

| # | 操作 | 预期 | 备注 |
|---|---|---|---|
| A1 🔥 | CLI 冷启动 | 日志依次出现：知识库同步（新增/删除/不变）、图谱同步、当前模型、全局工具清单；无 traceback | 换目录启动也成立（`cd /tmp` 再跑，路径全锚 `WORKSPACE_ROOT`） |
| A2 🔥 | Web 冷启动，开四个面板 | 各面板不空白、无 500；对话页能发消息 | 只绑 127.0.0.1 |
| A3 | 空会话第一句话 | 回答带人设（自称/边界一致，不飘英文） | 验 ensure_persona 不变量 |
| A4 | 连续 `/new` 两次再发消息 | 每次开新会话都正常；`data/memory/sessions/` 多出新文件，老会话原样在盘 | S8a 身份=文件名 |

## C. plan-then-act（060/061/062 三刀新机制，重点区）

| # | 操作 | 预期 | 备注 |
|---|---|---|---|
| C1 🔥 | 触发 make_plan → 弹窗点「拒绝」 | 计划不建，模型改口直接做或追问 | 人审掌舵点 |
| C2 🔥 | 批准计划后观察步骤推进 | `update_plan_step` 逐步回写，任务视图 ○◐● 同步变 | Web 任务面板展开 Run 详情 |
| C3 | 计划里故意不含某工具，执行中诱导它用（如计划只说读笔记，中途让它跑命令） | 范围闸程序拒绝，拒绝串指路「用 make_plan 修订」；修订要再过一次人审 | ⚠️ 活清单「白名单声明过窄」在案：修订吃一轮预算，5 轮内可能来不及 |
| C4 | 做一个与历史失败相似的计划（先看 `data/plan_failures.jsonl` 里有什么，再复刻一个同主题任务） | make_plan 回灌带「历史相似失败」段，模型显性回应（改向或说明为何不同） | 060 查重软拦：不硬拦，看模型反应 |
| C5 | 建计划后问一个 learned 里有记录的主题 | make_plan 回灌尾部带「相关经验」段（命中才出现，零命中不出现） | 061：纯中文计划零命中是**已知局限** |
| C6 | 收官时让 summary 与计划明显不符（如两步 failed 却说「全部完成」） | finish_plan 触发回验 → 弹窗转人审；人拒则计划留 active 不归档 | 062：回验器故障一律放行（宽容语义） |
| C7 | 正常完成计划收官 | finish_plan 一次通过，**无弹窗**（正常收官零摩擦） | 与 C6 是一对 |

## K. 已知怪癖（遇到不要当新 bug 报）

- deepseek-flash 偶发 DSML 泄漏：回答里出现 `<｜｜DSML｜｜` 标记残骸。**结构性根因已修两处**（056 收尾段恒 tools=None→收官菜配套；066 路由 direct 分支→泄漏重试升全量菜单，实机样本＝2026-09-29「今天天气怎样」→「上海」3 连泄漏）；残余＝模型侧随机吐 markup（结构正常时也可能），salvage 机制会截断救回前半，**纯标记型会只剩一句故障告知**。触发信号=升菜单后仍 3 连失败（届时议路由带上文）。
- `max_tool_rounds=5`：复杂计划 + 多次修订会抢预算，模型会**逐字说明**「预算用完了」——这是告知机制按设计工作，不是卡死（在案，纪律：不是简单调大常量）。
- 冻结集相关的非确定性翻红（spawn_step 焊点、judge 单采样自相矛盾）——都在活清单，按 046 纪律不据单次读数报 bug。
- flash 价目是占位值，账单成本略高估（在案）。

## 反馈格式（报问题时带上这四样，定位快一个量级）

1. **会话 id**：`data/memory/sessions/` 里的文件名（时间戳那个）；
2. **审计行**：`data/audit/audit-YYYYMMDD.jsonl` 里对应时段的行（工具名、参数摘要、`guard` 字段都在里面）；
3. **复现步骤**：从哪句话开始、点了什么；
4. **预期 vs 实际**：一句话说清你本以为会发生什么。
