## 关键概念的大白话

- **记忆（M2）**：模型本身失忆。所谓"记得"，是程序把完整对话历史每轮重发一遍给它读。
- **RAG（M3）**：模型不知道我的私人笔记。所谓"基于资料回答"，是先检索出相关笔记拼进问题再发。
- **工具（M5）**：模型只会说不会做。所谓"会做事"，是它"点菜"（说要调哪个工具、什么参数），我们的 Python "做菜"，结果端回去它继续决策。模型从头到尾没执行过任何代码——**决策权在模型，执行权在程序**。
- **放权（M5.5）**：以前程序强制每句话都查资料（闲聊也查）；现在检索只是桌上一个按钮（search_notes 工具），它自己决定按不按、怎么按。
- **复杂度塌缩（M5.5 彩蛋）**：放权后，为"塞资料"而生的 30 多行代码（备份历史/替换消息/拷回正史）整段蒸发。主循环 121→87 行，**代码更少，能力更强**。

## 它现在是谁

一个能对话、有会话记忆、会语义检索自己的笔记、能读写笔记文件、并自己决定何时检索的个人 AI 学习助手。全部自研无框架，约 700 行。

## 我的学习方式（也是给自己看的）

每一步都是「讲原理 → 一起实现 → 我动手扩展」。我亲手写过：EchoLLM/RepeatLLM（接口练习）、read_notes（第一个带参工具）、write_note 骨架（含最难的路径穿越检查）、search_notes 骨架（Agentic RAG 核心）。踩过的坑（标注子串差一个字、复制粘贴残渣、删码前不查引用）都沉淀在 data/notes 和项目记忆里。
