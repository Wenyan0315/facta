# 决策记录 · 联网工具（2026-09-16）

> 场景「个人助理」的核心缺口补齐；定位见 product.md（内部归档）。返回 [architecture.md](../architecture.md)

- **联网工具落地（2026-09-16，两次真实使用实测失败催生）**：「查天气」「股市分析」皆因无实时数据失败——014 产品定位当天即用数据驱动排序把联网顶到最前（定位一页纸的机制首次运转）。**①两个工具**：`web_search(query)`（搜索 top5：标题+URL+摘要，摘要 500 字截断）+ `fetch_web(url)`（GET→html2text 转 markdown，8000 字截断）；摘要已清洗是 Tavily 的选型要点——查天气类一步到位，多数场景省掉 fetch。**②搜索 Provider 供应商化（第四次）**：`WebSearchClient` 协议 + `TavilySearch` 实现（httpx 手写 REST，两行的 API 不引 SDK——手写 MCP 同哲学）；key 走 `TAVILY_API_KEY` 环境变量（.env 纪律）。**双 Provider 路由（中文博查/英文 Tavily）架构留位未实现**：触发信号 = Tavily 中文实测不达标时加 BochaProvider + 语言路由（配置表一行）——先用免费额度拿真数据说话，不被博查充值流程卡住端到端。**③条件注册**：`ToolContext.web` 缺席（无 key）→ 两工具不上菜单（与 kb=None 同语义，mock 路径零联网依赖）；TYPE_CHECKING 导入防 context↔web 循环。**④随行安全栅栏（S3 提前开门的最低防护，014 裁定）**：scheme 白名单（拒 file://）；私网地址拒绝——**DNS 解析后逐 IP 检查**（只查 hostname 字符串挡不住「域名解析到 127.0.0.1」的绕过；云元数据 169.254.169.254 在拒列）；只读 GET；超时 10s/15s；响应 2MB 流式截断（不整搬进内存）+ 正文 8000 字。已知边界：DNS rebinding TOCTOU 个人工具 v1 接受，S3 完整栅栏再议。**⑤接线**：assemble 读 key 建 client（有才建）→ ctx.web → register_web_tools；html2text 进 rag 可选组（真模型路径增强，与 httpx 同组）+ 工具内延迟导入（chromadb 同招）；SYSTEM_PROMPT 自我画像同步（有的能力要声称——「没有的能力不得声称有」的对称面）。**⑥html2text 选型**：轻量纯 Python、表格/代码保留，胜过纯正则（表格全烂）与 trafilatura（重）。测试 170→183（条件注册双态/schema 必填项/结果格式化+摘要截断/空结果提示/七类危险 URL 拒绝/域名解析到私网拒绝+公网放行对照/超长正文截断——全假 client 离线，不真联网）。真网络验收待 key 注册后做（Tavily 免费注册即得）。同轮顺手：侧栏归档列表显示时间（文件名身份→展示层格式化「09-15 23:15」）。
