# ADR 112：评审 Agent 单独工具轮次预算

- 状态：**已裁定**（2026-10-19，用户指令「先解决」，当日实现）｜日期：2026-10-19
- 上游：[111](111-v01-review-prototype.md)（V01 真机验证·摩擦登记）、[100](100-plan-authorized-rounds-budget.md)（轮次预算先例：计划授权扩容）、[056](056-dsml-leak-root-cause-closing-menu.md)（保险丝收尾段）、[046](046-frozen-real-task-eval.md)（不为单轮读数建机制——本案有 4 例真机证据，非单轮）。
- 调整关系：提前解决 111 摩擦登记里「等 V02 自用数据攒够再议」的预算项；其余摩擦（Web 壳无账单出口）不在本案范围。

## 背景

`Agent.max_tool_rounds` 默认 5（S5a 从全局常量 `_MAX_TOOL_ROUNDS` 归位进 Agent 对象）。
一轮 = 一次模型调用（批内可含多个工具调用）；预算耗尽走 `_close_out` 强制文字总结
（ADR 056：「工具预算已用完…请直接用自然语言总结：完成了什么、哪些没做完」）。

111 真机验证（deepseek-flash，外部仓 4 例）中 **3/4 例自报「工具预算已用完」**：

- 例 4 只读了 main.py 的前 40 行（全文 299 行），后续核实只能降级为「待验证」；
- 例 2 同样「工具调用额度已用完，`.git` 历史等进一步核实未做」；
- 即评审输出里的「待验证」段，相当部分是**保险丝熔断后的收尾话术**——证据收集
  被预算截断，不是模型自愿的诚实标注。这对评审是结构性的伤害：098 评审范围②
  要求「文件/入口/命令/接口前提必须去仓库里读文件核实」，而分页读一个 300 行
  文件就要 3 个 read_file 窗口，5 轮预算装不下「读完 + 复核」。

## 裁定

1. **评审 Agent 单独预算 `REVIEW_MAX_TOOL_ROUNDS = 12`**，常量住 `facta/review.py`
   （调教区，与 `REVIEW_TOOLS`/`REVIEW_SYSTEM_PROMPT` 同居——改词不改码的同一纪律）。
2. **落点 = `build_review_agent` 既有的 replace 行扩一笔**：
   `replace(agent, allowed_tools=REVIEW_TOOLS, max_tool_rounds=REVIEW_MAX_TOOL_ROUNDS)`
   ——与 `allowed_tools` 同款手法。不动 `Agent.max_tool_rounds` 全局默认（chat 主链、
   spawn 子 agent、冻结评测臂逐字节不变）；不动 `build_default_agent` 签名（它刻意
   省略 max_tool_rounds：默认值住 dataclass，工厂里再写一遍 = 将来改默认要改两处）；
   不加 env 可配（无调参需求，YAGNI）。
3. **数值依据**：12 = 默认 5 的 2.4 倍。典型小仓评审路径 = 浏览 1–2 轮 + 定位
   1–2 轮 + 读关键文件（批内并行多窗口）+ 复核 1–2 轮 ≈ 6–8 轮自然收束；12 给
   「读完 + 复核」留余量。三重既有保险丝保证放大预算不放大风险：`_STUCK_LIMIT=3`
   原地踏步熔断独立于预算（P0-6）；泄漏重试上限不吃预算（047）；056 收尾段兜底。
   12 是保险丝不是常态成本——模型点完菜即自然退出，V01 四例审计显示单例实际
   调用 4–16 次不等，从未主动刷满过。
4. **与 100（计划授权预算）的关系**：100 的语义是「人批了多大的活，就给多少行动
   额度」（make_plan 与 L2 人审重合）；评审不用计划板（111 裁定 4：评审 registry
   无计划工具），没有授权点可挂——固定常量是评审的最小等价物。不引入「材料
   长度 → 预算」动态映射：V01 摩擦只证明「5 太小」，不支持任何具体曲线。

## 边界（不做的）

- **不改全局默认 5**——评测臂（046 纪律：被测物不动）、spawn 子 agent、chat 主链
  全部行为不变；评审预算差异由 `build_review_agent` 一处注入。
- **不做 env / 动态 / 按仓库大小自适应**——调参信号挂 V02 自用数据，出现「12 仍
  不够」或「12 明显浪费」的形态再议（后续 ADR 编号顺延）。
- **不动 `_close_out` 收尾话术**——111 真机显示「预算用完→自然语言总结」在评审
  语境产出的正是「待验证」诚实段；熔断后的降级行为是对的，问题只在熔断来得太早。
- **不回填复跑 111 四例**——预算是保险丝，行为差异由测试钉住；V02 真实自用时
  自然检验（12 是否够用作为 V02 观察项）。
