# 决策记录 · M6.5 用户级记忆位置（2026-09-23）

> 记忆主线第五站（M6.1 持久化→M6.2 压缩→M6.3 温层→M6.4 项目级固化→M6.5 用户级位置）。返回 [architecture.md](../architecture.md)

## 立项依据（三线交汇）

- **021 方向定稿**：记忆护城河是三大支柱之一——本站把护城河从项目级扩展到个人级（跨项目资产，换 agent 带不走）。
- **M6.4 红线解扣**：「三桶刻意不含 preferences——用户级位置（仓库外）未实现，开桶=引导隐私写进可能公开的 repo」。位置建成，红线从「一律不记」升级为「分流」——能力跟着位置走。
- **032 调研 + 漏网实证**：Trae 两层结构（全局 user_profile.md / 项目 project_memory.md）正是本站参照；阳澄湖行程条目混进 constraints 桶（用户级内容无合法出口，管线压力下硬挤项目桶）是立项的直接痛点证据。

## 拍板（六件）

1. **位置与形态**：`~/.personal-agent/user.md` 单文件起步（Trae 全局层同款）。不预拆桶——用户级偏好量小，检索分层挂 032 裁定二 v2 信号（注入 token 成本阈值）。
2. **写侧分流**：固化管线一次跑两个作用域——萃取条目带 `scope`（project/user），项目级照旧进桶，用户级 append 到 user.md（同款行格式，读侧零翻译）。铁律 2 从「用户级一律不记」改为「敏感凭证不记 + 用户级分流」。
3. **敏感禁令（程序侧硬边界）**：API key / password / Bearer / 身份证 18 位 / 手机号，正则硬校验拦在落盘前，任何作用域都不例外。保守取向：宁误杀不漏放（11 位纯数字可能是订单号，但漏放一个手机号的代价远大于误杀一条硬事实）。提示词也禁（语义引导），但代码才是边界——「信模型语义，不信模型纪律」。
4. **审查从宽**：scope=user 条目依据不够直接即弃——用户级记忆跨项目影响所有会话，污染代价远高于漏记（learned 幻觉污染前科的量级放大版）。
5. **子 agent 不注入（临期修正）**：设计草案原定「主子一视同仁」，读 spawn.py 实现后改判——子 agent 是专项执行器不是陪伴者（system_prompt=自包含任务书，router 同为 None），它不直接面对用户表达，注入用户画像只会稀释任务书。用户级记忆只进主 agent。
6. **记忆面板用户级分栏**：挂可选子项未做——面板是信任支柱，用户级画像更敏感更该可见，但不阻塞本站主线；触发信号=用户级条目积累到需要查看/编辑的真实摩擦。

## 实现（四层 + 三消费端）

- **位置层** [paths.py](../../src/agent/paths.py)：`user_memory_path()` 函数——默认值 `~/.personal-agent/user.md` 唯一真值源，`CORTEX_USER_MEMORY` 环境变量覆写（测试 tmp_path 隔离注入点，S6a WORKSPACE_ROOT 同款）。函数而非常量：覆写逻辑跟真值源走，三消费方不散三份。
- **写侧** [consolidate.py](../../src/agent/memory/consolidate.py)：Entry 加 scope 字段（缺省 project，旧输出兼容）；_harden 加 scope 白名单（非法归 project——保守方向：错进项目桶是噪音，反向是隐私泄漏）+ 敏感正则禁令；_append 按作用域分叉两个落盘位置；_load_known 跨作用域去重（user.md 也进「已知记忆」）。
- **读侧** [agent.py](../../src/agent/orchestrator/agent.py)：`_user_memory_block` 拼在项目桶之后——顺序契约：项目上下文优先确立，用户画像殿后。块头与 _learned_block 同构（时效+免疫）+ 独有定位（「关于用户本人」的记忆，用来理解和服务这个用户）。
- **装配** [assemble.py](../../src/agent/orchestrator/assemble.py)：主 agent 构建传 user_memory_path()；CLI 退出复盘与 Web 归档两个 consolidate 调用点同步传参。user_memory_path=None（防御默认）= v1 行为（user 条目丢弃），文案如实汇报。

## 边界（不做什么）

- 不做检索分层（032 v2 信号未触发，用户级初始量小全量注入零压力）
- 不做跨设备同步（Trae 也明说不做；触发信号=多设备真实需求）
- 不动项目级三桶现状（M6.4 管线四段原样复用，只加分流不改既有路径）
