## 裁定：不立项「笔记时效标记/四态」，挂回信号

- **触发信号未兑现**：knowledge-update 首轮 2/6 垫底、二轮 5/6 并列
  第二高——「连续两轮垫底」的两轮门槛正确过滤了单轮 alarm（046 的
  「≥n 才动」纪律在跨外部基准场景再次兑现）。
- **首轮 alarm 的成分**：分题型 n=6 的轮间摆动达 ±3 题，叠加活清单
  已登记的「LLM-judge 单采样自相矛盾」——单轮垫底读数在这个粒度上
  噪声太大，这正是 058 把门槛设成「连续两轮」的原因。
- 053 的「tombstone 删除语义仍未做」登记**维持**（它的触发信号另有
  `memory_add` 写路径开闸一途）；本 ADR 只关闭 319 条的题型侧信号一
  个轮次——下次锚定跑若 knowledge-update 再垫底，与再下次连续即
  重新构成「连续两轮」。
- 预算执行：二轮实付 ¥0.31 + 废轮 ¥0.035 = ¥0.345，远低于 097 预定的
  ¥10 顶。

## 边界
