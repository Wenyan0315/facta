# 决策记录 · 方向定稿四联裁定（2026-09-18）

> 待讨论清单出清会：产品定位 / S5 投法 / 编排形态 / 前端框架化，按依赖链（地基→中游→下游）一次定稿。返回 [architecture.md](../architecture.md)

- **①产品定位定稿（product.md 升 v2，[014](014-product-positioning.md) 加修订注记）**：外部评审「三场景并列=没定位 vs 押知识伴侣」的二选一被第三条路化解——**场景押执行**（个人执行助手：能写代码、能扛复杂任务，主轴）＋**能力押记忆**（极强个人记忆为横切护城河——是能力不是场景，取评审「记忆最值钱」的前提、弃「押问答」的结论）＋**通用性来自用户身份开放**（溢出效应而非设计目标，因果句写死防退化回三场景并列）。三场景表降级为「溢出记录」（内容不丢，身份从设计目标变结果清单）；数据台账角色改为溢出证据（主轴是定位问题不由数据决定，数据只排外延生长顺序）。差距点名：执行恰是当前最弱一环（run_turn 纯反应式无规划、任务视图半成品带 bug）——定位与现状的最大差距即路线图主攻方向，直接引出②。

- **②S5 重定义：不是二选一，是吸收**：重读路线图发现 S5 原三件中有两件天然是 Agent 对象的砖——SYSTEM_PROMPT 外置（行为定义与执行引擎分离，Agent 对象化的同一哲学超集：全局配置文件→每个 agent 有自己的 prompt）与 AGENTS.md 式 learned 读取侧（恰是评审属性表中的「记忆」属性）；真正独立的只有技能包格式（能力打包 vs 执行单元，两种抽象）。**新 S5 = Agent 对象抽象（吸收上述两件）+ plan-then-act（执行主轴的地基；plan 即 Human on the Loop 的掌舵点）+ spawn_subagent（子 agent 只回传结论=噪声隔离，S6 判据提前兑现）**；技能包格式后置并入 S6。S5 的「学到什么」从「插件化」变为「执行架构」。细节留草案（临期定）：spawn 隔离边界（只回传结论/工具子集由主 agent 指定/轮数预算注入）；plan 载体倾向独立最小结构而非复用 TodoStore——TodoStore 是跨会话个人资产（用户视角待办），plan 是单任务生命周期执行状态（agent 视角工作分解），语义与生命周期皆不同，复用会互相污染（评审「天然可复用」只看了字面相似）。

- **③编排形态：编辑与阅读分治**：编辑侧=agent.md 声明式文本（git 可 diff、agent 自己可读写、表单化辅助成本低）；阅读侧=agent.md 内嵌 mermaid 块 + 前端 vendored 渲染（与 marked 同款零构建链待遇）。**拖拽式编辑进否决档案**（Dify 条的延伸裁定）：图形化编辑使配置退化为不可 diff 的二等公民；触发信号=出现「不用画布编辑就理解/维护不了」的多 agent 流程（届时框架化已就位）。排期不变：S5（Agent 对象）之后才有东西可编。

- **④前端框架化：翻案（veto 触发信号兑现）**：2026-09-15 否决的前提「vanilla 舒适区内」已不成立——S2b 起确认弹窗/任务视图/会话管理连续叠加（521 行 JS + 306 行 CSS，主要复杂度是「状态同步矩阵」：每条 API × 每处显示它的 DOM），任务视图偶发不切换的 DOM 竞争 bug 是病灶样本，评审药方（记忆面板/工具叙事/溯源跳转/配置表单）排队超舒适区。**裁定 Preact + Vite**：选 Preact 不选 Svelte 的唯一理由是 React 心智模型=业界 agent UI 生态（LangGraph Studio、各家 SDK 组件库）的最大公约数——本项目学前端学的是「状态即真相、DOM 是投影」的概念，概念的通用语言是 React 形状。**迁移策略：不做一次性大迁移，任务视图重写作试点**——独立页面、带 bug 半成品、定位定稿后的重投主战场，一石二鸟（结构性验证 DOM 竞争 bug 随声明式渲染消失，兑现「框架化时一并排查」触发信号；不伤主聊天视图）。试点成→记忆面板（护城河可视化，高优）等新前端需求上新栈长，主聊天视图渐进迁移；零构建链让位于构建链（代价接受，FastAPI 静态伺服架构不变）。排期：地基工程，S5 开工前（记忆面板等前端需求压在它上面）。

- 讨论方法注记：四条按依赖链走（S5→编排→框架化）而非并列过——顺序反了会被 UI 需求倒逼上框架，正着走每步由上游结论推动；产品定位独立于链外但实为链的源头（定位押执行→S5 重定义→编排有东西可编→前端需求加重→框架化翻案）。待讨论清单出清后余「混合检索」一条（评估数据到位前不动）。
