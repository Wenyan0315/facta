# 043 检索分诊：事实走向量、多跳走图（search_notes 图谱导航补强）

> 状态：已实现（2026-09-25）｜日期：2026-09-25
> 数据依据：[035](035-s7a-knowledge-graph.md) 消融实验补录 + roadmap 刺 #3 预写规则判定（「L2 赢→继续投入」已兑现）

## 背景与动机

graph_ablation.py 判定数据（词袋/BGE 两 embedder 同趋势）：

- L1 单篇事实：打平，块数成本 1.75→2.2——无脑融合的噪声成本（论文⑥预言）
- L2 跨笔记：**图谱赢**（词袋 0/4→2/4，BGE 2/4→3/4）
- L3 多跳：各 +1；定性组（孤岛全集/不连通如实报告）是向量检索结构性给不出的
- 反方读数（035 已录）：embedder 是一阶效应、图谱是二阶增量——所以**不做全量融合，做门控分诊**：只在向量不自信时才麻烦图谱

现状问题：`search_notes`（纯向量）与 `query_graph` 并列菜单，「什么题走哪条路」靠模型自判。M10 的教训是模型自判不如程序分诊（轮首一针 19/20）；028 划定 Jev 适用域=原子决策——检索分诊恰是原子决策候选，但不必急着动用路由。

## 选项

- **A. 轮首路由加检索类型**（Jev 判 factual/relational → 控制首菜单形状）：与 028 同机制；但「检索类型」判别力未经 bench 验证，Jev prompt 加类需重校准
- **B. search_notes 弱命中门控追加图谱导航**（向量不自信时才走图）：消融实验组机制的直接产品化；L1 强命中不追加 → 零成本；纯程序逻辑零新增 LLM 调用
- **C. 只改 query_graph 菜单描述引导模型自决**：最便宜，但正是被 M10 数据否过的「模型自判」路线，单独用效果存疑

## 拍板（草案）

**B 为主，C 伴随，A 挂触发信号。**

B 的设计要点：

1. **无条件导航**（与消融实验同款）：base = `kb.search(query, top_k=3)` 照旧格式化；图谱导航块作为补充段落追加、去重保序（base 块总在前）。原「分数门控」被 BGE baseline top1 分布**证伪**——L2 miss 题的 top1（0.682）反而高于 L1 命中题的 top1（0.641），语义向量下「相关但非答案」同样高分，分数区分不了「有没有答到点上」；**L1 零成本改由图的自然空集承担**：孤岛锚点（RAG/余弦/PHP）导航返回空、零追加，只有枢纽锚点（如 Agent）多付 1—2 块、但答案块总在前、噪声可控
2. **导航机制**：query 与图节点名/别名字面锚定（子串匹配，零 LLM 调用）→ 实体 BFS **2 跳**（1 跳只回到锚点笔记自己——边 source_note 是抽取来源，实验已证 2 跳才拿到邻笔记）→ 沿途边 source_note 去重限量 → 每篇取词袋最相关 1 块追加；独立段落标注「图谱导航」+ 注入界碑声明（图谱是 LLM 抽取产物，包裹声明随块走）
3. **追加上限 2 篇**：上下文成本可控
4. **降级**：graph 未装配 → 静默跳过；kb 检索为空时图谱导航仍可单独成立（纯图回答路径）
5. **C 伴随**：query_graph 菜单描述补一句适用场景（多跳关系/全貌类问题优先）——一行改动

A 挂触发信号：B 上线后实机 L2 类 miss 仍多（信号=用户报告「关系类问题答非所问」≥2 次），再上路由级分诊。

## 判定标准（验收用什么数据说话）

evals/graph_ablation.py 场景集即回归基线：

- L1：命中率不降（词袋 2/4、BGE 4/4 回归值不变），追加块数增幅 ≤1（孤岛锚点应零追加）
- L2：增量保持（词袋 ≥2/4、BGE ≥3/4）
- 新增用例：孤岛锚点 L1 题（RAG/余弦/PHP）的返回文本不得含「图谱导航」段（导航空集，零追加）

## 反方（预写）

1. **L2 仅 4 题小样本**——结论强度=方向性决策依据（035 反方读数）；上线后实机观察补数据
2. **场景集按图谱优势区间出题（自我出题嫌疑，刺 #4）**——L2/L3 题是「被构造出来让图谱赢」的形状；上线后实机使用观察补数据，若实机 miss 仍多再回头校准
3. **022 已判混合检索不立项，本案是不是翻案？**——不是。022 判的是 grep 补向量（字面互补，BGE 变强后增量衰减至 0）；本案是图谱补向量（结构互补：路径/全集/实体导航是向量给不出的维度）。互补轴不同；本案自带「embedder 越强图谱增量越窄」的警惕——不靠分数门控（BGE 下证伪），改靠图的自然空集（孤岛锚点零追加）+ 追加块上限控成本

## 不做（防范围蔓延）

- 不动 query_graph 工具本身与图谱抽取（图覆盖补盲是另一活清单项）
- 不动轮首路由（A 挂信号）
- 不动 search_and_summarize（复合工具单独评估）

## 实现与验收（2026-09-25）

实现三点（最短 diff）：

1. **GraphStore.related_notes(query, hops=2, limit=2)**：实体锚定（节点名/别名子串匹配，零 LLM）→ BFS 2 跳 → 沿途边 source_note 去重限量。抽成图原语（与 neighbors/path/overview 并列），**evals/graph_ablation.py 同步改为调用它**——导航逻辑单一真值源，工具层与实验层不各写一份（042「围栏单一真值」同款纪律）
2. **search_notes**：base 照旧；graph 非 None 时 unconditional 追加 `_nav_blocks`（每篇候选笔记词袋选 1 块，去重），独立段落标「图谱导航」+ 注入界碑声明；graph 缺席静默跳过；base 与导航双空才报「没有相关内容」
3. **query_graph 描述**（C）：补一句 path/overview 是 search_notes 导航给不出的独占能力

验收证据：

- 三道门全绿：ruff / mypy（58 文件）/ pytest **510 passed, 2 skipped**（新增 8 例：test_graph.py related_notes 5 例 + test_search_triage.py 导航 3 例）
- 消融回归一致：单一真值源重构后 evals/graph_ablation.py 输出逐项不变（词袋 L1 2/4→3/4、L2 0/4→2/4、L3 0/2→1/2；BGE L2 2/4→3/4）——导航逻辑搬家未改语义
- 测试钉住三不变量：孤岛锚点零追加 / 链锚点追加邻笔记块 / 无图静默降级
