# 否决档案（活清单）

> 被否决的方案、否决原因、重新考虑的触发信号。迁自「业界调研与路线图吸收」记录（2026-09-15 v0.37 拆分独立成活清单）；后续否决持续追加。返回 [architecture.md](../architecture.md)

- **Tab 补全 / Cue 预测**：IDE 壳层能力，回本需海量用户——触发信号：产品形态真变成 IDE 时
- **云会话迁移（Cursor 3 云↔本地 handoff）**：需要云基建——触发信号：多用户/团队版排期时
- **RepoWiki 十万文件级规模**：S7 的 v0.1 够用即止——触发信号：代码库知识化需求实测出现时
- **Dify 式可视化 DAG 编排（2026-09-15）**：物种错配——Dify 是「给非开发者搭应用的低代码平台」，编排逻辑搬进画布是它的核心价值；coding agent harness（Claude Code 51 万行/OpenCode/Cursor/Trae 六标无一直观可视化 DAG）的灵活性应长在提示词+工具菜单+skill（高频开关），编排结构（循环/工具环/取消检查点）留代码更可靠可测试——触发信号：产品形态真变成「给不会编程的人搭 agent 的平台」时（那时已是另一个产品）
- **前端框架化 React/Vue（2026-09-15）**：前后端已分离（纯静态三件 + 纯 API 契约），框架化只服务 UI 复杂度——零构建链是刻意选择，当前 vanilla JS 舒适区内框架是纯负债（构建链/依赖升级/状态管理）；触发信号：diff 视图语法高亮+虚拟滚动、复杂状态管理让 vanilla JS 开始难受时
  - **翻案（2026-09-18，[021](021-direction-decisions.md)）**：触发信号兑现——S2b 起确认弹窗/任务视图/会话管理连续叠加（vanilla 521 行，主要复杂度为「状态同步矩阵」），任务视图 DOM 竞争 bug 为病灶样本，评审药方（记忆面板/工具叙事/溯源跳转/配置表单）排队超舒适区。裁定 **Preact+Vite**（React 心智模型=业界 agent UI 生态最大公约数），任务视图重写作试点；零构建链让位于构建链（代价接受，FastAPI 静态伺服架构不变）。
- **拖拽式 agent 编排编辑（2026-09-18，[021](021-direction-decisions.md)）**：Dify 条（2026-09-15）在编排配置场景的延伸裁定——编辑走声明式文本（agent.md：git 可 diff、agent 可读写、表单化辅助），阅读走 mermaid 渲染（vendored，与 marked 同款零构建链待遇）；图形化编辑使配置退化为不可 diff 的二等公民——触发信号：出现「不用画布编辑就理解/维护不了」的多 agent 流程（届时框架化已就位）
