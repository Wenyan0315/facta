# 知识图谱

## 定义

知识图谱（Knowledge Graph）是把知识表示为**实体（节点）和关系（边）构成的网络**的技术。现实世界中的对象抽象为实体，对象之间的关联抽象为关系，最终形成一张可查询、可推理的图结构网络。

## 与 Embedding 的关系

知识图谱依赖 **Embedding 技术**把实体（以及关系）向量化：

- 实体经过 Embedding 模型编码后变成稠密向量，语义相近的实体在向量空间中距离更近；
- 向量化之后，图谱可以支持语义层面的实体链接、相似实体发现、关系补全与链路预测；
- 反过来，知识图谱中的结构信息也可以作为约束或监督信号，帮助优化 Embedding 的质量。

## 与向量数据库的关系

知识图谱依赖**向量数据库**来存储和检索这些实体向量：

- 向量数据库负责承载大规模实体向量与索引（如 HNSW、IVF 等近似最近邻索引）；
- 提供高效的相似度检索能力，支撑「按语义找实体」「找与某实体最相关的邻居」这类查询；
- 是图谱与语义检索之间的桥梁：图谱负责结构与推理，向量库负责相似度召回。

## 三者的关系链路（小结）

```
知识图谱 --依赖--> Embedding --产出--> 实体向量 --存储于--> 向量数据库
```

即：**Embedding 负责把知识表示成向量，向量数据库负责把这些向量存好查快，知识图谱负责把这些向量与关系组织成可推理的网络。**

## 备注

本文中「知识图谱依赖 Embedding 做实体向量化」「依赖向量数据库存储与检索向量」两条关系，属于知识图谱笔记的核心论述，若后续做图谱关系抽取，应能抽取出「知识图谱 --依赖--> Embedding」与「知识图谱 --依赖--> 向量数据库」两条边。
